# Sirius Custom Vulnerability Templates

This repository provides ready-to-use templates for:
- OpenVAS (Greenbone)
- Nessus Essentials

## Usage
1. Run OpenVAS / Nessus scan externally
2. Export scan result (XML / .nessus)
3. Add this repository in Sirius UI:
   Settings → Repositories → Add
4. Select template → Upload report → Start scan

No scanner installation required inside Sirius.
